## Qué se implementó

### Datos (Prisma + SQL manual — Luis aplica)
- Modelo `GmailThread` (`gmail_threads`): FKs lógicas contactId/dealId/userId (sin Prisma relations), `@@unique([userId, threadId])`.
- `Activity` += `gmailThreadId`, `gmailMessageId` (único parcial), `googleEventId` (único parcial, reservado GW-2).
- Enum `WorkflowActionType` += `GW_GMAIL_LOG_INBOUND`, `GW_GMAIL_LOG_OUTBOUND`.
- SQL: `prisma/migrations-manual/2026-06-15-gw1-gmail.sql` (additivo, idempotente).

### Backend
- `src/lib/google/gmail.ts`: `sendGmail` (MIME RFC2822 base64url), `logOutboundSend` (log inline con contactId conocido), `logGmailMessageById`, `processGmailHistory` (delta sync por `gmailHistoryId`; primer run solo fija baseline, sin backfill), `getThreadMessages` (cuerpo on-demand). Match contacto = exacto contra `Contact.email`; respeta `doNotContact`; dedup por `gmailMessageId`.
- `actions.ts`: handlers `GW_GMAIL_LOG_INBOUND` (corre el delta sync) y `GW_GMAIL_LOG_OUTBOUND` (log diferido por messageId).
- Rutas: `POST /api/google/gmail/send`, `POST /api/google/gmail/webhook` (Pub/Sub → encola sync), `GET /api/google/gmail/threads/[threadId]`, cron `GET /api/cron/google/gmail-sync` (x-cron-secret).

### UI (estética B/N existente)
- `email-rich-text.tsx` (Tiptap v3, toolbar mínima B/I/listas/link, `immediatelyRender:false`).
- `email-composer-drawer.tsx` (slide-over: To prellenado, asunto, cuerpo rich text + firma de `UserProfile.emailSignatureHtml`).
- `email-thread.tsx` (expand on-demand del hilo).
- `ActivityLog`: nueva prop `contactEmail`; botón "Enviar email" (si Gmail conectado + email); ítems `EMAIL_*` con "Ver hilo completo". Pasado desde contact-detail y deal-detail.
